# 07. 보너스: 코호트 재구매율 분석

- 예상 시간: 4시간
- 선행 단계: [06. 보너스 이미지 특성](06-bonus-image-features.md)
- 다음 단계: [08. 보너스 인터랙티브 차트](08-bonus-interactive-chart.md)

## 목표

고객의 시작 월에 따라 이후 월별 구매 지속/재구매 패턴을 계산하고 히트맵으로 시각화한다.

## 작업

1. 01단계에서 정한 코호트 기준을 적용한다. 가입일이 있으면 **가입 월**, 없으면 **첫 구매 월**을 사용한다. 차트 제목에 실제 기준을 명시한다.
2. 거래 날짜를 월 단위로 변환하고, 코호트 월로부터 경과한 개월 수를 계산한다.
3. 가입 월 코호트는 해당 월 가입 고객 수, 첫 구매 월 코호트는 해당 월 첫 구매 고객 수를 분모로 삼는다. 각 경과 월의 구매 고객 수와 비율을 집계하며, 동일 고객의 같은 월 중복 구매는 한 명으로 센다.
4. 아직 도달하지 않은 미래 월 또는 관측 기간 밖의 셀은 결측으로 두고 0%로 채우지 않는다. 관측 가능한 기간이 코호트마다 다른 점을 해석에 반영한다.
5. 코호트 크기와 월별 비율을 함께 보여 주는 히트맵을 만든다. 작은 코호트의 수치에 대해 과도한 결론을 내리지 않는다.
6. 재구매 패턴에서 확인되는 관찰과, 이를 검증하는 데 필요한 추가 데이터를 한 단락으로 적는다.

## 산출물

- 코호트별 고객 수·경과 월별 활동 고객 수·비율 표
- 코호트 히트맵과 노트북 해석

## 완료 기준

- [ ] 첫 구매 월 코호트의 0개월 차 비율은 100%다. 가입 월 코호트에서는 실제 가입자 대비 구매 비율을 표시한다.
- [ ] 고객-월 중복이 제거되고 미래/미관측 셀은 0%로 오표기되지 않는다.
- [ ] 코호트 기준과 표본 수가 차트/해석에 드러난다.
