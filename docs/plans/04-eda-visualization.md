# 04. EDA, 통계 분석, 필수 시각화

- 예상 시간: 10시간
- 선행 단계: [03. 분석 파이프라인](03-data-pipeline.md)
- 다음 단계: [05. RFM과 고객 세분화](05-rfm-segmentation.md)

## 목표

데이터 구조와 품질을 수치로 설명하고, 전처리 효과 및 주요 관계를 필수 6종 차트로 보여 준다.

## 작업

1. `notebooks/analysis_report.ipynb`에 데이터 소개 → 기본 탐색 → 결측/이상치 처리 → 피처 분석 → 통계 해석의 흐름을 만든다.
2. `head()`, `info()`, `describe()` 결과를 제시하고, 각 결과에 **수치 근거 1개 이상 + 시사점 1문장 이상**을 적는다.
3. 주요 수치형 변수의 평균·중앙값·표준편차·사분위수를 계산한다. 가격·주문금액 등 치우친 분포는 평균과 중앙값 차이도 해석한다.
4. 서로 다른 변수 쌍 **2개 이상**의 상관계수를 계산하고 수치와 사업상 의미를 설명한다. 상관관계를 인과관계로 단정하지 않는다.
5. 결측 처리 전후의 누락 수와 IQR 처리 전후의 분포·행 수를 비교한다.
6. 아래 차트를 각 1개 이상 작성한다. 모두 제목과 축 레이블을 포함하고 필요한 경우 단위·표본 수를 표시한다.

   | 유형 | 분석 대상 예시 |
   | --- | --- |
   | 히스토그램 | 상품 가격 또는 주문금액 분포 |
   | 박스플롯 | IQR 처리 전후 가격/주문금액 |
   | 막대그래프 | 상품 카테고리별 빈도 |
   | 히트맵 | 수치형 변수의 상관행렬 |
   | 산점도 | 가격과 이미지/텍스트 파생 변수 |
   | 라인차트 | 월별 매출 추이 |

7. 차트에 대응하는 짧은 해석을 마크다운으로 작성한다. 실제 계산값을 인용하고 과도한 일반화를 피한다.

## 산출물

- 설명이 포함된 분석 노트북 전반부
- 6종 정적 차트와 핵심 차트의 `outputs/figures/` 이미지
- 결측·이상치 처리 전후 비교표
