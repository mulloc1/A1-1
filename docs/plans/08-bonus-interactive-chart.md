# 08. 보너스: Plotly 인터랙티브 시각화

- 예상 시간: 3시간
- 선행 단계: [07. 보너스 코호트 분석](07-bonus-cohort-analysis.md)
- 다음 단계: [09. 문서화와 최종 검증](09-documentation-verification.md)

## 목표

RFM 세분화 결과를 독자가 직접 탐색할 수 있는 차트로 제공한다.

## 작업

1. Plotly로 세그먼트별 고객 수·매출 기여 또는 고객별 RFM 분포를 보여 주는 차트를 만든다.
2. 범례 선택과 마우스오버에서 세그먼트 이름, 고객 수, 비율/금액 등 해석에 필요한 값이 보이도록 한다.
3. 차트 제목, 축 이름, 단위, 색상 범례를 명확히 한다. 고객별 점을 표시할 경우 고객 ID 등 개인정보가 노출되지 않도록 집계 또는 익명화한다.
4. 노트북에서 차트가 정상 표시되는지 확인한다. 별도 HTML 파일이 재현에 도움이 되면 출력 경로와 생성 방법을 문서화한다.
5. 필수 6종 차트는 Matplotlib/Seaborn으로 유지하고, Plotly는 이 보너스 차트에만 사용한다.

## 산출물

- 노트북의 인터랙티브 RFM 차트
- 필요 시 재생성 가능한 HTML 차트

## 완료 기준

- [ ] 범례와 마우스오버가 작동하고 표시 수치가 RFM 요약표와 일치한다.
- [ ] 제목·축·단위가 명확하며 고객 식별 정보가 노출되지 않는다.
- [ ] 필수 정적 차트 6종을 대체하지 않는다.
