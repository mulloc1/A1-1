# 09. README, 전체 재현, 제출 검증

- 예상 시간: 8시간
- 선행 단계: [08. 보너스 인터랙티브 차트](08-bonus-interactive-chart.md)
- 다음 단계: GitHub 저장소 URL 제출

## 목표

다른 사람이 데이터를 준비하고 노트북을 재실행해 같은 분석 결과를 확인할 수 있도록 문서와 산출물을 마무리한다.

## 작업

1. `README.md`에 프로젝트 개요, 데이터 출처·라이선스·규모·컬럼, 분석 흐름, 주요 차트, 실행 방법, 한계를 적는다.
2. 05단계 인사이트 초안 중 **3개 이상**을 실제 최종 수치로 갱신한다. 각 항목에 **근거(수치/그래프) + 실행(대상·방법·기대 효과) + 검증(추가 데이터 또는 반증 가능성)**을 넣는다.
3. 노트북의 커널을 초기화하고 첫 셀부터 끝까지 한 번에 실행한다. 숨은 수동 단계나 개인 경로가 없는지 확인한다.
4. 결과 일관성을 확인한다.
   - 원본·전처리·분석 대상 행 수와 고객 수
   - 이미지 피처의 유한값과 결측 대치 전후 수
   - IQR 경계값·이상치 수 및 처리 전후 분포
   - RFM 고객 수와 거래 총액/고유 구매일 수의 집계 일치
   - 세그먼트 고객 수 합계 및 코호트 비율의 분모·집계값 일치
   - README의 수치와 노트북 최종 출력 일치
5. 모든 정적 차트의 제목·축 이름·단위와 한글 표시를 확인하고, README에서 인용할 그림을 `outputs/figures/`에 저장한다.
6. 의존성에 금지 라이브러리가 없는지, 데이터 출처가 누락되지 않았는지, 예시 수치가 실제 결과처럼 남아 있지 않은지 확인한다.
7. 새 환경에서 README 절차를 따라 설치·데이터 준비·노트북 실행을 검증한 뒤 GitHub 저장소 URL을 제출한다.
