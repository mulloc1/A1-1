# 03. `DataAnalyzer` 분석 파이프라인

- 예상 시간: 12시간
- 선행 단계: [02. 프로젝트 구조와 환경](02-project-setup.md)
- 다음 단계: [04. EDA와 정적 시각화](04-eda-visualization.md)

## 목표

원본을 보존하면서 적재·전처리·기본 피처 엔지니어링·RFM 계산을 재사용 가능한 `DataAnalyzer` 클래스로 구현한다.

## 작업

1. `src/pipeline.py`에 `DataAnalyzer`를 만든다. 상품/거래 원본, 전처리 결과, RFM 결과를 서로 구분해 관리한다.
2. 필수 메서드를 구현한다.

   | 메서드 | 책임 | 주요 인자 |
   | --- | --- | --- |
   | `load_data()` | CSV·이미지를 읽고 필수 컬럼, 자료형, 날짜, 연결 키 검증 | 경로, 날짜·금액 컬럼 |
   | `handle_missing_values()` | 컬럼별 결측 현황과 그룹별 통계 대치 | 대상·그룹 컬럼, 평균/중앙값 전략 |
   | `detect_outliers()` | Q1·Q3·IQR·경계값을 직접 계산하고 이상치 반환 | 대상 컬럼, IQR 배수(기본 1.5) |
   | `calculate_rfm()` | 고객별 마지막 구매일·고유 구매일 수·구매금액 집계 | 고객·날짜·금액·기준일 |

3. 그룹별 대치값이 없는 경우 전체 평균/중앙값 등 명시적 보조 전략을 적용한다. 대치 전후 결측 수를 보존한다.
4. IQR **탐지**와 이상치 **처리**를 구분한다. 제거 또는 경계값 절단을 선택할 수 있도록 하되 원본을 덮어쓰지 않고 처리 전후 행 수·분포를 남긴다.
5. 상품명 단어 수 또는 문자열 길이를 파생 변수로 만든다.
6. 이미지 묶음을 같은 형상으로 정리한 뒤 `np.stack`과 축을 지정한 `np.mean`/`np.std`로 **이미지별 평균·표준편차**를 계산한다. 이미지 파일을 읽는 반복은 허용하되, 픽셀 특성 계산에는 이미지별 `for` 반복문을 쓰지 않는다.
7. CSV의 이미지 배열이 문자열이면 `ast.literal_eval()` 또는 NumPy 파싱으로 복원하고 형상·값 범위를 검증한다. 이미지 크기를 줄여야 한다면 NumPy 슬라이싱을 사용한다.
8. 거래 데이터에서 취소·반품·중복·음수 금액을 01단계에 정한 규칙대로 처리한다. Recency 기준일은 기본적으로 **최종 거래일 다음 날**로 고정하고 실제 기준일을 결과에 남긴다.
9. 주요 전략과 임계값을 메서드 인자로 받게 한다. 잘못된 컬럼명과 빈 데이터에 대한 오류 메시지를 명확히 한다.

## 산출물

- 데이터 적재·전처리·기본 피처 생성·RFM 계산 결과
- 처리 전후 품질 및 행 수 요약
