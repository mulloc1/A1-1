# 05. RFM 계산, 고객 세분화, 사업 인사이트

- 예상 시간: 8시간
- 선행 단계: [04. EDA와 정적 시각화](04-eda-visualization.md)
- 다음 단계: [06. 보너스 이미지 특성](06-bonus-image-features.md)

## 목표

거래 기록에서 고객별 구매 행동을 계산하고, 최소 4개 그룹의 차이를 수치로 설명한다.

## 작업

1. 고객별 `Recency = 기준일 - 마지막 구매일`, `Frequency = 고유 구매일 수`, `Monetary = 구매금액 합계`를 계산한다. H&M에 주문 ID가 없어 같은 날 여러 주문을 구분할 수 없다는 한계를 적고, 상품 구매 기록 수는 별도 지표로 제시한다.
2. 기준일을 최종 거래일 다음 날 또는 명시적 분석 기준일로 고정해 노트북에 표시한다.
3. R은 작을수록, F/M은 클수록 높은 1~5점이 되도록 점수화한다. 동일값이 많아 분위수 경계가 중복되면 순위 또는 명시적 임계값을 쓰고 선택 이유를 적는다.
4. 점수 규칙을 표로 공개한다. **VIP, Loyal, New, Churned** 등 최소 4개 세그먼트를 만들되 실제 데이터 분포에 맞게 이름과 규칙을 정한다. 어떤 고객도 중복되거나 누락되지 않도록 기본 분류 규칙을 둔다.
5. 세그먼트별 고객 수·비율, 평균 R/F/M, 총매출·매출 비중을 비교한다. 작은 그룹의 수치가 우연에 민감할 수 있음을 해석에 반영한다.
6. `README.md`에 실을 인사이트 **3개 이상**의 초안을 만든다. 각 인사이트는 다음 구조를 따른다.
   - **근거:** 실제 수치 또는 차트 1개 이상
   - **실행:** 대상 세그먼트, 구체적 액션, 기대 효과
   - **검증:** 추가로 필요한 데이터 또는 반증 가능성 1문장
7. 기대 효과로 제시하는 목표 수치는 관찰된 결과가 아니라 가설임을 분명히 하고, 검증할 지표를 정한다.

## 산출물

- 고객별 RFM·점수·세그먼트 표
- 세그먼트 요약표와 시각화
- README용 수치 기반 인사이트 초안 3개 이상

## 완료 기준

- [ ] RFM 고객 수가 유효 고유 고객 수와 일치한다.
- [ ] 고객별 Frequency가 고유 구매일 수와 일치하고 Monetary 합계가 표본 고객의 전체 구매 기록 합계와 일치한다.
- [ ] 4개 이상 세그먼트가 상호 배타적이고 모든 고객을 포함한다.
- [ ] 인사이트마다 근거·실행·검증 요소가 있다.
