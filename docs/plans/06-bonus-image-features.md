# 06. 보너스: 이미지 고급 특성

- 예상 시간: 3시간
- 선행 단계: [05. RFM과 고객 세분화](05-rfm-segmentation.md)
- 다음 단계: [07. 보너스 코호트 분석](07-bonus-cohort-analysis.md)

## 목표

이미지 평균·표준편차를 넘어 밝기 분포와 간단한 엣지 강도를 NumPy 배열 연산으로 수치화한다.

## 작업

1. 03단계에서 정리한 이미지 배열을 사용한다. RGB 이미지라면 밝기로 변환하는 계산식과 값 범위를 문서화한다.
2. 고정된 구간의 밝기 히스토그램을 계산하고, 상품별 저·중·고 밝기 비율 등 비교 가능한 피처를 만든다. 이미지마다 픽셀 수가 달라도 비교할 수 있도록 비율로 정규화한다.
3. `np.diff`로 수평·수직 이웃 픽셀 차이를 구하고 절댓값 평균 등 간단한 엣지 강도를 상품별로 계산한다.
4. 입력이 빈 배열이거나 이미지가 누락된 경우 처리 규칙을 적용하고, 정상 이미지의 결과가 유한값인지 확인한다.
5. 새 피처의 분포와 가격/카테고리 등과의 관계를 노트북에 요약한다. 피처가 어떤 시각적 특성을 대략 나타내는지와 한계를 적는다.

## 제약

- OpenCV와 Pillow를 사용하지 않는다. 이미지 읽기는 허용된 `imread()`를 사용할 수 있으나, 특성 계산은 NumPy로 직접 한다.
- 파일 입출력 반복은 가능하지만 픽셀 처리에는 배열 연산을 사용한다.
